# T-040: Per-agent GitHub credential injection

## Description
Inject GitHub credentials into agent environments. Each agent gets a scoped, short-lived token derived from the user's OAuth token. Agents never hold long-lived tokens.

## Acceptance Criteria
- [ ] Each agent receives a scoped credential
- [ ] Credentials are short-lived (max 1 hour)
- [ ] Agent environment has GITHUB_TOKEN set
