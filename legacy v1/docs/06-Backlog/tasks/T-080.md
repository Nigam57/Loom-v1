# T-080: Budget metering proxy

## Description
Implement the API-key-based budget metering proxy. Track spend per agent, enforce budgets, and block requests when budget exceeded. API-key setups only (no proxy for native auth).

## Acceptance Criteria
- [ ] Budget tracked per agent in cents
- [ ] Requests blocked when budget exceeded
- [ ] Budget reset available per session
