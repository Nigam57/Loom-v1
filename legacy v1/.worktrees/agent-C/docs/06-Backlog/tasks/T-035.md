# T-035: Approval UI (HITL)

## Description
Provide a way for Human-in-the-Loop (HITL) interaction within a Conversation Room. Agents that require approval (`supports_approval` capability) should pause the router and await manual continuation from the user.

## Acceptance Criteria
- [x] AgentAdapter traits expose `supports_approval`
- [x] Router emits `StopReason::NeedsApproval` when a turn is completed for such agents
- [x] Flow view can resume or inject manual replies
