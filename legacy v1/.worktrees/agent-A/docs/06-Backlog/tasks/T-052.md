# T-052: AppContainer isolation wrapper

## Description
Implement Windows AppContainer-based isolation for extension execution. Extensions run in a restricted sandbox with minimal filesystem/network access. Only ambient permissions are explicitly granted.

## Acceptance Criteria
- [ ] Extension processes run inside AppContainer
- [ ] Filesystem access limited to extension directory
- [ ] Network access requires explicit grant
