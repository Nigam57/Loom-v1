# T-042: DPAPI secret storage

## Description
Implement Windows DPAPI-based secret storage for OAuth tokens, API keys, and other credentials. No plaintext storage. Encrypted at rest, decrypted only in-process.

## Acceptance Criteria
- [ ] Secrets encrypted with DPAPI CurrentUser scope
- [ ] No plaintext files on disk
- [ ] Decrypt only returns value, never writes plaintext
