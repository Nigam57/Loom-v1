# T-034: Adapter factory

## Description
Create an adapter factory that selects the appropriate adapter (HeadlessJson or PtyAdapter) based on detected CLI capabilities. Use the detect_agents results to determine which adapter to use.

## Acceptance Criteria
- [ ] Factory selects HeadlessJsonAdapter for CLIs with stream-json support
- [ ] Factory falls back to PtyAdapter for CLIs without stream-json
- [ ] Factory is configurable per-CLI in config
